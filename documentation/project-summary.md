# Project Summary

## Project Title

**Indonesia Socioeconomic Dashboard (2020–2025)**

---

## Objective

To analyze poverty, unemployment, population, and GDP per capita across Indonesian provinces from 2020 to 2025 and transform raw public datasets into meaningful insights through SQL and Power BI.

---

## Dataset Sources

Data was collected from official publications provided by **Badan Pusat Statistik (BPS)** and consolidated into a master dataset.

Variables included:

* Province
* Year
* Poverty Rate
* Unemployment Rate
* Population
* GDP per Capita

---

## Project Workflow

### Data Collection

Collected and consolidated provincial-level socioeconomic data from multiple BPS publications covering the years 2020–2025.

### Data Cleaning

Performed:

* Data validation
* Data type standardization
* Missing value checks
* Consistency verification

### Exploratory Data Analysis

Analyzed:

* Poverty statistics
* Unemployment statistics
* Year-over-year trends
* Provincial comparisons

### Business Analysis

Identified:

* Provinces with the highest poverty rates
* Provinces with the lowest poverty rates
* Provinces with the highest unemployment rates
* Relationship between GDP and poverty
* Poverty improvement between 2020 and 2025

### Dashboard Development

Built an interactive Power BI dashboard featuring:

* KPI Overview
* Poverty Trend Analysis
* Unemployment Trend Analysis
* Top Poverty Provinces
* GDP vs Poverty Scatter Plot
* Poverty Improvement Ranking

---

## Key Findings

* Poverty peaked nationally in 2024.
* Unemployment steadily declined from 2020 to 2025.
* Papua region consistently experienced the highest poverty rates.
* GDP per capita alone was not a reliable indicator of poverty reduction.
* Papua achieved the largest poverty reduction during the study period.
